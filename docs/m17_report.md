# M17 审查结果可视化报告页

- 日期：2026-11-03
- 端点：`GET /report/{task_id}`（`src/api/review_app.py` + `src/api/templates/report.html`）
- JSON `/result` 语义不变；报告页是 JSON 之上的只读视图
- 不引入前端框架、构建步骤或 JS

## 1. 状态与页面

| 任务状态 | HTTP | 页面行为 |
|---|---|---|
| queued | 200 | 显示「排队中」，`<meta http-equiv="refresh" content="30">` 自动刷新 |
| processing | 200 | 显示「审查中」，30 秒自动刷新 |
| done | 200 | 完整报告 |
| failed | 200 | 「审查失败」+ 错误原因（自动转义） |
| 过期 | 410 | 「任务已过期」，结果已按保留策略清理 |
| 不存在 | 404 | 「任务不存在」 |

## 2. 报告内容（done）

1. 结论头部：整体结论（存在高风险 / 存在风险 / 未检出风险）、风险条数、
   审查时间、tokens（prompt / completion / total）。
2. 风险卡片：中文风险类型、严重程度、原文摘录、判定来源
   （「规则命中」/「LLM 判定」）、explanation 原样展示（含计算式）。
3. 无风险：明确显示「未检出风险条款」，并列出本次覆盖的 9 项检查清单；
   文案强调「没查出」不等于「没查」。
4. `other_observations` 若有，单独显示为「其他观察（不计入风险）」。
5. 页脚免责声明：自动审查结果仅供参考，不构成法律意见。

风险类型中文映射在 `RISK_TYPE_NAMES`；未识别的类型显示「其他风险」，
不直接暴露英文枚举。

## 3. 样式与转义

- 单文件内联 CSS；高/中/低风险卡片用左边框颜色区分。
- `@media print`：避免卡片跨页断开，打印时去掉边距。
- Jinja2 `Environment(autoescape=True)` 显式开启；文件名、原文摘录、
  explanation、observations 都来自用户上传或 LLM，全部按不可信输入转义。
- 无 JavaScript。

## 6. 边界

- 报告页只读；不提供重跑、删除、下载、历史列表。
- 没有登录/用户体系；任何拿到 task_id 的人都能看（与当前 `/result` 一致）。
- 自动刷新只对 queued/processing 生效；done/failed/过期/不存在不刷新。
- 页面文本依赖任务记录中的 result JSON；JSON 仍是唯一事实来源。
