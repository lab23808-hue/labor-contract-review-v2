## 1. 规则

从清洗文本中提取：

- 试用期工资：`试用期(期间|间|内)?(的)?(月工资|工资) ... 数字 元`
- 转正工资：优先 `转正(后)?(的)?(月)?工资`，否则 `月工资|月薪`

支持阿拉伯数字与汉字金额（含十/百/千/万、壹贰叁…拾佰仟），匹配前移除
全部空白。两个数字齐备且 `试用期工资 < 转正工资 × 80%` 时报告
`wage_below_floor`（rules，medium），explanation 带计算式，例如：

```
试用期工资 9000 低于转正工资 12000 的 80%（9000/12000=75% < 80%）
```

恰好 80% 不报；缺任一数字不报；只出现试用期工资时不会被误当作转正工资。

## 5. 已知边界

1. 缺任一数字不报：只有试用期工资、没有转正工资参照时无法判定，防误报优先。
2. 非数字比例表述不解析，例如「试用期工资为转正工资的 80%」没有具体金额。
3. 「试工期」等变相叫法不在本规则关键词内；仍由 LLM 卡片负责。
4. 汉字金额支持常见与财务大写，但混合写法（如「1万2千」）不在本轮范围。
